# Build & Track ML Pipelines with DVC

## How to run?
```bash
python -m venv .venv python=3.11
```
```bash
. .venv/bin/activate
```
```bash
pip install -r requirements.txt
```

## DVC Commands
```bash
git init
```
```bash
dvc init
```
```bash
dvc repro
```
```bash
dvc dag
```
```bash
dvc metrics show
```
